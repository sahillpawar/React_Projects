Techiemindz — Responsive Landing Page

View locally:
- Open `index.html` in a browser, or
- Serve the folder and open the shown URL.

Python (recommended if available):
```bash
python3 -m http.server -d /workspace/techiemindz 5173
```

Node alternative:
```bash
npx serve /workspace/techiemindz -p 5173 --single
```

Files:
- `index.html` — semantic HTML structure
- `styles.css` — tokens, layout, components, responsive styles
- `main.js` — mobile nav toggle, smooth scrolling, dynamic year
